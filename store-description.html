Grand Chess

A chess variant that breaks free from the 8x8 grid. Play on boards from 3x3 up to a massive 99x99 squares, with multiple piece setup modes that create endless strategic possibilities.

Features

  • Variable board sizes - From tiny 3x3 puzzles to epic 99x99 battlefields
  • Multiple setup modes:
    • Standard - Dynamically configure how many piece ranks to place and how many of those are pawn ranks
    • Custom - Design your own starting positions with mirroring support
  • Configurable pawn first move - Choose how many squares a pawn can advance on its very first move
  • Play your way - Local Player vs Player, challenge the AI, or play online
  • FEN support - Import and export positions to share with others
  • Intuitive controls - Pan, zoom, and navigate large boards with ease

Online Multiplayer

Play against friends online using session codes (no IP sharing or servers needed). Just exchange short codes via Discord (or any messaging app) to start a game.

  1. Host clicks "Create Game" and waits for a session code to be generated
  2. Host copies the session code and sends it to the other player (via Discord, chat, etc.)
  3. Joiner clicks "Join Game", pastes the host's code, and clicks "Join"
  4. Joiner copies their response code and sends it back to the host
  5. Host pastes the response code and clicks "Connect" - the game begins!
